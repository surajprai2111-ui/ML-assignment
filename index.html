Prioritizing Content Pages for Human Review

An exploratory comparison of a rule-based baseline and a Random Forest classifier using anonymized content-performance data.

Abstract

This project examines whether anonymized content-performance data can help content teams prioritize pages for human review. I compared a rule-based scoring baseline with a Random Forest classifier using a target derived from the existing trend_direction label. To evaluate performance on unseen clients, I used a client-grouped train-test split, with 25 clients in training and 7 in testing, and no client overlap. On the held-out test set, the Random Forest achieved an Average Precision of 0.5894, compared with 0.5008 for the rule-based baseline, an absolute improvement of 0.0886. These results suggest that the model may help rank pages with an observed declining trend for further investigation. However, the target represents an existing trend rather than future decline, and further validation is needed before practical use. The model should support human decision-making, not replace it.

1. Research Question

Can available content-performance data help identify pages that may need attention, and can a simple scoring system help a content team decide which pages to review first?

Content teams may have thousands of pages but limited time. A ranked review queue can help analysts decide where to investigate first.

2. Data

The analysis uses an anonymized content-performance dataset containing 30,000 rows and 44 columns. The main analysis includes pages with positive 90-day impressions and a content age of at least 90 days, with duplicate content IDs removed.

The target is derived from the existing trend_direction label: pages labelled “down” are marked as declining, while other labels are grouped as not declining. This target describes an existing trend, not a future outcome.

3. Methodology

I compared a rule-based scoring baseline with a Random Forest classifier. Evaluation used a client-grouped train-test split so that clients in the test set were not present in training.

5. Limitations

  • The target represents an existing trend, not a future decline outcome.
  • The evaluation uses one client-grouped train-test split.
  • Some performance features may describe the same period used to define the target, so they may not be suitable for future forecasting.
  • The baseline was designed to help prioritize review and may not have been optimized for the same classification task.
  • The analysis is observational and does not prove that changing content causes traffic or ranking improvements.

6. Ranked Recommendations

  1. Use the model as an additional signal for prioritizing human review, not as an automatic decision-maker.
  2. Inspect impressions, clicks, sessions, average position, content age, and search intent before selecting an action.
  3. Match any content update to the issue identified by an analyst, rather than changing pages solely because of a model score.
  4. Validate the approach on additional unseen clients or a later time period and collect reviewer feedback.

A high score is a reason to investigate, not proof that a page will decline in the future.
